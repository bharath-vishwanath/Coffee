# Coffee
coffee business blueprint

## Coffee Business Workspace

Single-file app: [`coffee-workspace.html`](coffee-workspace.html). Tabs: Goals, ToDos, People, Business Ideas, Research. Overview strip, JSON export/import, sample data with a "Clear sample data" button.

### Run locally

Open the file in a browser:

```bash
open coffee-workspace.html
```

Or serve it:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000/coffee-workspace.html.

### Data

Outside Claude, edits are saved in the browser's `localStorage` (this browser and origin only). Use **Export JSON** to back up. Clearing site data erases it.
